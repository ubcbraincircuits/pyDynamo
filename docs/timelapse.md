# Dendritic arbor timelapse

pyDynamo tracks how a neuron's dendritic arbor changes over time. The plot below is an
interactive 3D reconstruction of a single arbor across 11 imaging timepoints — drag to
rotate, scroll to zoom, and use the play/slider controls to step through the timelapse.
Branches are coloured by identity, the soma is marked in white, and points removed between
timepoints are shown in red.
